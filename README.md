Rally brings useful student opportunities into one calm, searchable place. Browse first, verify from the official organizer, then make your next move with the information that matters.

> [!TIP]
> Start at [rally.kamolpop.dev](https://rally.kamolpop.dev/), choose a category, and open the official source before applying or registering.

## Explore opportunities

| Discover | Use it for |
| --- | --- |
| Internships | Company, university, and practical work opportunities |
| Hackathons | Build, learn, and meet collaborators |
| Competitions | Challenges, awards, and student programmes |
| Ambassador programmes | Community, campus, and creator roles |
| Student guides | Practical preparation for applications and events |

Rally is available in English and Thai, with responsive pages designed for quick scanning on mobile or desktop.

## A directory you can trust

- **Official-source links:** Each public listing points back to the organizer or programme page.
- **Clear status:** active, upcoming, watchlist, and expired explain what the listing means.
- **Reviewed details:** Unknown information stays unknown instead of being guessed.
- **Local-first discovery:** The directory is built for students in Thailand and the opportunities around them.
- **No account required:** Save interesting listings locally in your browser.

> [!IMPORTANT]
> Rally is a discovery directory, not an application service. Deadlines, eligibility, and availability can change, so confirm the latest details on the official source.

## Opportunity status

| Status | Meaning |
| --- | --- |
| active | A current application or registration is supported by evidence. |
| upcoming | An official future opening or named cycle is confirmed. |
| watchlist | The programme recurs, but its next intake is not announced. |
| expired | A useful past cycle retained for reference. |

## Report a problem

Found an incorrect link, logo, organizer, deadline, status, or duplicate? Open the [listing or organizer correction form](https://github.com/ArmmyC/Rally/issues/new?template=data-correction.yml) and include:

1. The Rally listing or exact title.
2. The official source that supports the correction.
3. A short explanation of what should change.

For a website bug, use the [website problem form](https://github.com/ArmmyC/Rally/issues/new?template=bug_report.yml). For a product idea, use the [feature idea form](https://github.com/ArmmyC/Rally/issues/new?template=feature_request.yml).

## Contribute

This repository is Rally's public project and community home. It contains the project README, feedback workflows, and contribution guidance.

- Read [CONTRIBUTING.md](./CONTRIBUTING.md) before opening a pull request.
- Follow [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md) when participating.
- Read [SECURITY.md](./SECURITY.md) for private vulnerability reports.
- Application code and reviewed data are maintained in the [Rally-Source repository](https://github.com/ArmmyC/Rally-Source).
